# ЛР 9. Решение по гипотезе H1

**Отклонить безусловную замену целых слов на символьные n-граммы.** Прирост macro-F1 составил 0,044 вместо требуемых 0,10. Ошибочные переходы выросли с 23 до 27, а ошибочные действия по запросам `other` — с 2 до 6 из 8. Символьные признаки помогли на 7 из 10 ошибок со словоформой и улучшили результат на опечатках с 20 до 23 из 29. Этого недостаточно для подтверждения H1 по [протоколу](experiment_plan.md).

Оба варианта не проходят ни один из пяти численных порогов alpha из ЛР 8. У кандидата accuracy 0,508 при цели 0,75, macro-F1 0,469 при цели 0,70, доля ошибочных переходов 0,429 при лимите 0,10. Baseline остаётся точкой сравнения. Test из 58 запросов сохранён для итоговой оценки варианта, прошедшего отбор на validation.

Вывод относится к коротким фразам набора clean v2 и одной фиксированной символьной схеме. На живых запросах пользователей, новых тематических словах, других языках и других видах опечаток эффект неизвестен. Повтор того же детерминированного прогона проверил воспроизводимость. Частота успешных переходов пользователей, влияние фильтра ролей и выбор кнопок требуют проверки в интерфейсе.

Из 21 ошибочного действия кандидата на запросах к разделам в 16 случаях правильный вариант есть среди трёх кнопок. Отдельный эксперимент H3 может сравнить автоматическое действие с предложением вариантов по порогу уверенности. Для него нужно заранее зафиксировать порог или процедуру его выбора, считать ошибочные переходы и сохранение правильного варианта отдельно. Сырые ответы и все защитные метрики E01 сохранены в [сравнении](comparison.md).
