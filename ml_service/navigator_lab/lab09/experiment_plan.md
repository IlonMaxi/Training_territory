# ЛР 9. План эксперимента H1

Проект Training Territory, ИИ-навигатор. Протокол зафиксирован по [гипотезе ЛР 8](../lab08/hypothesis.md) до первого запуска сравнения.

**H1.** Замена словесных признаков на символьные n-граммы длины 3–5 внутри слов даст абсолютный прирост macro-F1 на validation не менее 0,10. Неполное совпадение слова должно помочь связать словоформы и запросы с опечатками.

| Показатель | Правило принятия |
|---|---|
| Macro-F1 по 12 классам | Прирост ≥ 0,10 относительно baseline по неокруглённым значениям |
| Ошибки со словоформами | Исправлено минимум 5 из 10 ошибок baseline из этой группы |
| Опечатки | Больше 20 верных ответов на тех же 29 зафиксированных вариантах ЛР 8 |
| Ошибочные переходы | Не больше 23 из 63 (0,365 после округления) |
| Намерения с нулевым recall | Не больше 3 |
| Ошибочные переходы по запросам `other` | Не больше 2 из 8 |

Для подтверждения H1 нужны все шесть условий. Выполнение H1 и готовность alpha проверяются отдельно. Пороги alpha взяты из [спецификации ЛР 8](../lab08/metric_spec.md). Доступность раздела проверяется интерфейсом по роли, а доступ к данным проверяется сервером. Офлайн-оценка считает предполагаемое действие модели по правилам ЛР 8, без моделирования действий пользователя.

## Конфигурация

| Параметр | Значение |
|---|---|
| Код сравнения | `lab09/__main__.py`, общая реализация TF-IDF в `baseline.py` |
| Baseline | Целые слова после приведения регистра и замены «ё» на «е» |
| Кандидат | Те же слова с пробелом с обеих сторон, разложенные на n-граммы 3–5, аналог `char_wb` |
| Данные | clean v2, SHA-256/16 `60d80a7acb7eb7fa`, разметка `6a87b4a2b6b32175`, 12 намерений |
| Разбиение | Train 193, validation 63, test 58. Существующий групповой split с seed 1 из ЛР 6 |
| TF-IDF | Частота × сглаженный IDF, L2-норма. Словарь признаков и IDF каждого варианта строятся только по train |
| Решение и tie-break | Намерение ближайшего запроса train по косинусному сходству. Округление оценки до 6 знаков, при равенстве сортировка по `query_id` |
| Ответ и метрики | Пустой вектор даёт отсутствие ответа. Метрики и правила `other` из `metrics.py` и `analysis.py` |
| Диагностика | Три разные кнопки по полному списку соседей без `other`. Сегменты и типы ошибок закреплены по baseline |
| Окружение | Python 3.10+, стандартная библиотека. Версия интерпретатора, параметры и хеши train-IDF записываются в `summary.json` |
| Случайность | В обучении и прогоне отсутствует |
| Команда из `ml_service` | `python -m navigator_lab.lab09` |

Текст запросов, метки, фильтры, пороги уверенности и обработка стоп-слов остаются прежними. Выбор делается по validation. Test предусмотрен для итогового контроля выбранного варианта после фиксации решения. При отсутствии прошедшего кандидата test сохраняется для следующего эксперимента.
