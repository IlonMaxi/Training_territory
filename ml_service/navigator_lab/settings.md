# Настройки baseline

| Параметр | Значение и назначение |
|---|---|
| Данные | `data/intents_clean_v2.csv`, версия 60d80a7acb7eb7fa из ЛР 6. Источник - `ml_service/intent_data.json` коммита b973fb9. 314 запросов, 12 намерений |
| Train | 193 запроса: по ним строятся словарь и IDF, среди них ищется ближайший запрос |
| Validation | 63 запроса, по ним считаются все метрики |
| Test | 58 запросов, в ЛР 7 не используется |
| Признак | Только текст запроса. `query_id` нужен лишь для порядка при равных оценках; `label_a`, `label_b` и `group` в модель не входят |
| Токены | Нижний регистр, ё заменяется на е, слова из букв и цифр. Стоп-слова, опечатки и формы слов не обрабатываются |
| Вес слова | Число повторов в запросе * (ln((1 + N) / (1 + df)) + 1), N и df по train, вектор нормируется по длине |
| Решение | Намерение самого похожего запроса train по косинусному сходству. Три ближайших запроса сохраняются для разбора |
| Неизвестные слова | Игнорируются. Если в запросе нет ни одного слова из словаря train, ответа нет, и это считается ошибкой |
| Одинаковые оценки | Сходство округляется до 6 знаков, равные оценки упорядочиваются по возрастанию `query_id` |
| Метрики | macro-F1 по 12 намерениям - основная, как в ЛР 5; дополнительно accuracy и F1 по каждому намерению |
| Случайность | В самом baseline её нет. seed 1 использовался в ЛР 6 только для деления на выборки. seed 42 нужен только для бутстреп-интервала метрик: 1000 выборок внутри каждого намерения |
| Окружение | Python 3.10+ и стандартная библиотека; фактическая версия в `results/environment.json` (Python 3.10.9). scikit-learn нужен только для сверки формул в тестах |
| Хеш параметров | dc07b034fae4698c, считается по настройкам в `__main__.py` и меняется при любом их изменении |
| Команда | `python -m navigator_lab run` из папки `ml_service` |
