# ЛР 8. Метрики и анализ ошибок навигатора

Продолжение ЛР 7: та же модель baseline, те же данные clean v2 и те же 63 запроса validation. В этой работе выбрана система метрик с учётом цены ошибок, результаты разобраны по сегментам и типам ошибок, и сформулирована одна гипотеза для ЛР 9.

## Запуск

Из папки `ml_service`, нужен Python 3.10 или новее:

```powershell
cd ml_service
python -m navigator_lab analyze
python -m unittest navigator_lab.tests -v
```

`analyze` считает пороги, сегменты, матрицу ошибок, таксономию и специальные тесты и записывает файлы в `results/lab08`. Тесты класса `ManualCalculationTests` повторяют ручной расчёт, тесты класса `SpecialTests` - специальные проверки.

## Что сдать

| Материал | Где |
|---|---|
| Спецификация метрик | `metric_spec.md` |
| Ручная проверка метрик | `manual_calculation.md`, тесты `ManualCalculationTests` в `../tests.py` |
| Baseline по сегментам и намерениям | `error_taxonomy.md`, `../results/lab08/segments.csv` |
| Матрица ошибок | `error_taxonomy.md`, `../results/lab08/confusion_matrix.csv` |
| Таксономия ошибок и специальные тесты | `error_taxonomy.md`, `../results/lab08/error_taxonomy.csv`, `../results/lab08/special_tests.csv` |
| Вывод и гипотеза для ЛР 9 | `hypothesis.md` |
| Код анализа | `../analysis.py` |

Тип ошибки для каждого запроса записан в `../results/lab08/validation_cases.csv`, поэтому каждое число в таблицах можно проверить.

## Что изменилось в модуле по сравнению с ЛР 7

- Добавлены `analysis.py`, команда `analyze` и файл `data/annotations_v2.csv` с разметкой ЛР 6 (хеш 6a87b4a2b6b32175). Он нужен для сегмента «сложная разметка».
- `tokenize` теперь явно отклоняет нестроковый запрос с TypeError. Раньше None и числа падали с AttributeError, это нашёл специальный тест.
- Ответы baseline не изменились: `python -m navigator_lab run` даёт те же файлы с теми же хешами, что в ЛР 7.

## Критерии приёмки

| Критерий | Чем подтверждается |
|---|---|
| Выводы не основаны на одной aggregate-метрике | 5 порогов, 4 разреза сегментов с объёмами, метрики по 12 намерениям, матрица ошибок |
| У ошибок есть примеры и предполагаемая причина | Таксономия: 7 типов на validation и 4 специальных теста, у каждого частота со знаменателем, пример, причина с проверкой, ущерб и следующий шаг |
| Следующий эксперимент связан с наблюдением | H1 следует из 10 ошибок с формой слова и 9 ответов, которые ломает одна опечатка |
